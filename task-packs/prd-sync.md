# Task Pack · PRD Sync

Use when product intent, current code, and documentation are all present in the allowlist.

## Output

Create a candidate drift report with: confirmed current behavior, completed scope, changed intent, canceled scope, open work, and decisions requiring a human. Do not overwrite the original PRD.

## Validation

- Every behavior claim cites code or a verified run result.
- Conversation intent is not treated as current if a later project SSOT supersedes it.
- Candidate PRD is written only under the run root.
